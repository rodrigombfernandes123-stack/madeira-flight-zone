A carregar METAR de LPMA…

A tentar obter dados da Aviation Weather Center.

Importante

O METAR é um relatório meteorológico, não uma autorização para voar. Para decisões operacionais, confirma sempre a informação oficial e atualizada junto das fontes aeronáuticas competentes.

Se os dados não carregarem, pode ser uma falha temporária da API ou da ligação. Experimenta atualizar a página.
